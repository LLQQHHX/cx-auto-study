# 学习通自动化 油猴

一个跑在 Tampermonkey 里的学习通（超星）自动刷课脚本。

**打开课程页 → 装好脚本 → 它自己把课刷完。** 不配任何东西就能用；愿意配个 API Key，章节测验还能用 AI 做。

---

## ⚠️ 先读这三条

**1. 章节测验的成绩，取决于你有没有配 API Key**

- **不配** → 脚本随机蒙答案，**正确率看运气**
- **配了** → 调 DeepSeek AI 答题，约 **70~85%**

**2. 使用本脚本可能违反你所在课程或平台的规定**

由此产生的一切后果（包括但不限于**成绩无效、账号处罚**等）**由使用者自行承担**。详见文末[免责声明](#免责声明)。

**3. 长时间刷课记得关掉电脑睡眠**

否则电脑一睡，脚本就停了。

## 📝 章节测验怎么答

**这是唯一需要你选择的地方，两个模式：**

### 模式 A：不配 API（默认）—— 随机蒙

装完直接用，什么都不用管。

- **单选题**：随机选 1 个
- **多选题**：随机选 1 ~ (N-1) 个

**正确率 = 运气。** 四选一大概 25%，判断题 50%。

**适合：** 只求把课刷完、不在意测验分数、不想花钱。

### 模式 B：配 DeepSeek API —— AI 答题

填一个 Key，脚本把题干和选项发给 DeepSeek，让它判断答案。

| 课程类型 | 大致正确率 |
|---|---|
| 通识课 / 文科题 | **80%+** |
| 数学 / 编程题 | 70% 左右 |
| 校内自命题专业课 | 可能只有 60% |
| **图片题 / 公式截图题** | **0%（AI 读不到图）** |

**费用：一道题约 400 token，100 题约 4 分钱。**

**适合：** 在意测验分数、愿意花 2 分钟配 Key、能接受 4 分钱成本。

**怎么配：** 装好脚本打开学习通 → 点面板上的 **🤖 AI 设置** → 粘贴 Key → 看控制台出现「AI 测试结果: 通了」就成功了。详细见下一节。

> 两个模式随时可切：点「AI 设置」可以开启 / 关闭 / 清除 Key，不需要重装脚本。

## 🔐 关于 API 密钥（**配了 AI 的话必看**）

### 强烈建议：专门建一个密钥，只用来刷课

1. 去 [platform.deepseek.com](https://platform.deepseek.com) 注册
2. 创建一个 API Key
3. **只充 10~20 元**（一道题约 400 token，100 题约 4 分钱，20 元够你刷完整个大学）

**为什么要专用：** 万一这个密钥以任何方式泄露，损失上限就是你充的那 10~20 元，而不是你主账号的余额。

### 刷完课的标准动作

```
① 确认所有课程的任务点都变成绿色
② 点面板上的「🧹 清除所有痕迹」→ 确认
③ 看到「清理完成」提示后，按 F5 刷新页面
④ 去 DeepSeek 后台把这个密钥删掉
⑤ 下次要用时再建一个新的
```

### 为什么这么做

密钥存在浏览器本地（`localStorage`），**是明文的**（没有加密——因为脚本必须能读到明文才能用它发请求，加密等于白加密）。

理论上，下面这些人/东西能看到它：

- 同一域名下的 JavaScript（含学习通自己的脚本）
- 你装的**其他油猴脚本**
- 打开 F12 的人

**正常情况不会有人去读它。** 学习通没有动机（一个学生的 Key 值几块钱，法律风险却很高），主流开源脚本也不会干这种自毁信誉的事。

**但既然销毁再重建只要 2 分钟，不如把这个小概率事件一起堵上。**

**这就是"大概率没事，但顺手把路堵死"的做法。**

### 密钥不会泄露到别的地方

- 只发往 `api.deepseek.com` 这一个地址
- 脚本代码里**没有任何**把密钥上传到第三方的逻辑
- 仓库里的代码是干净的，**不包含任何人的密钥**

### 更保险的做法（可选）

刷课之前在浏览器里开一个**无痕窗口**（Ctrl+Shift+N），刷完直接关窗口，本地数据全清。

但要注意：Tampermonkey 默认**不在无痕模式下运行**，需要先去 `edge://extensions` → Tampermonkey → 详细信息 → 打开「允许在无痕模式下运行」。

## 🚀 安装

### ① 装 Tampermonkey（篡改猴）

- Chrome / Edge：[Chrome 应用商店](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- Firefox：[Firefox 附加组件](https://addons.mozilla.org/firefox/addon/tampermonkey/)

**Edge 用户注意：** 装完要确认扩展是启用的，并且 `edge://extensions` 里 Tampermonkey 的「开发者模式」打开，否则用户脚本不会执行。

### ② 装脚本

点 [`cx-auto-study.user.js`](./cx-auto-study.user.js) → 在打开的文件页面点右上角 **Raw** → Tampermonkey 自动弹出安装页 → 点「安装」。

或者把 `.user.js` 文件下载到本地，直接拖进浏览器窗口。

### ③ 打开学习通

进任意课程学习页，右下角出现 `📚 刷课` 面板就成功了。

**不需要按 F12，不需要按 Ctrl+F8。**

如果没看到面板，按 F12 打开控制台，能看到这三行说明脚本在跑：

```
[刷课v55] ✅ 脚本已注入
[刷课v55] 当前页面: <你的URL>
[刷课v55] 页面自检: video 元素 1 个 | 课程目录树 有 | tab 条 有
```

### ④（可选）配 AI 答题

点面板上的 **🤖 AI 设置** → 粘贴 DeepSeek Key → 确定。

控制台出现这条就成功了：

```
[刷课v55] AI 测试结果: 通了，模型回答 A
```

想关掉 AI 就再点一次按钮，选「确定要关闭吗」。

## 视频内弹题 —— 能保证答对

学习通在视频播放中途会弹出对错判断题。**这类题答错可以重选**，所以脚本会：

1. 随机选一个选项，点提交
2. 页面提示答错后，换下一个选项
3. 重复直到出现「恭喜你，答对了」

**因为可以重试，这个环节最终一定是对的——无论你配不配 AI。**

## 常见问题

### 为什么不用按 Ctrl+F8？

学习通页面会注入 `(function anonymous(){ debugger; })()` 来阻止调试。
但 `debugger` 语句**只在 DevTools 打开时才真的暂停**。油猴脚本不需要开 DevTools，所以这段注入对脚本完全无影响。

### 2x 播完任务点没完成怎么办？

学习通要求「观看时长 ≥ 总时长的 90%」，2x 播完实际只花了 50% 的时间，所以有些课不通过。

脚本会自动处理：检测到点下一节后章节没变，就降到 1.5x 重播；还不行降到 1.25x、1x。面板上「试速」一行能看到当前降速状态。

### 装了脚本但面板不出现？

按这个顺序排查：

1. **控制台有没有 `✅ 脚本已注入`？**
   - 没有 → Tampermonkey 没启用，或者脚本开关是灰的
2. **有没有 `⛔ 检测到考试/登录/成绩类页面`？**
   - 有 → 当前页面被主动排除，去课程学习页
3. **有没有 `⚠ 这个页面不像课程学习页`？**
   - 有 → 页面结构没加载完，刷新一次
4. **Edge 用户**：`edge://extensions` → Tampermonkey → 详细信息 → 打开「开发者模式」

### 填了 Key 但 AI 没生效？

看控制台这一行：

```
[刷课v55] AI 测试结果: 通了，模型回答 A     ← 成功
[刷课v55] AI 测试结果: 没通（...）          ← 失败
```

**失败的常见原因：** Key 复制少了字符、账户余额为 0、网络问题。

失败时脚本会自动关闭 AI 但**保留 Key**，你改完再点一次「🤖 AI 设置」即可。

**另外注意：** AI 只影响**填 Key 之后还没答的题**，已经答过的不会重答。

### 为什么状态偶尔变红？

一般是切到后台太久。浏览器会节流后台标签页的定时器，导致脚本以为卡住了。

切回前台后脚本会自动恢复（会打印「从后台恢复」日志），不需要手动干预。

**长时间刷课建议：让学习通窗口保持前台，或者单独放一个虚拟桌面；同时把电脑电源设置里的「睡眠」改成「从不」。**

### 卡住了怎么办？

1. 看面板「停滞」那一行，如果超时了，脚本会自动尝试三级自救
2. 自救无效会显示「自救无效，已停手」，这时刷新页面重新开始即可
3. 刷新后脚本会从当前章节继续

### 会不会重复执行？

不会。脚本内用固定的全局标记做了防重复注入检测，并且会检测其他版本是否已在运行。

但**不建议在脚本运行时再去控制台粘贴一次代码**，那会导致两套循环叠加。

## 面板说明

| 字段 | 含义 |
|---|---|
| 状态 | 当前在做什么（绿=正常，橙=等待，红=异常） |
| 倍速 | 当前实际播放倍速（对外伪装为 1x） |
| 试速 | 降速次数和降速阶梯 |
| 进度 | 当前视频播放进度 |
| 最远 | 本次播放到达过的最远位置（用于防回退） |
| 修复 | 回退修复次数 |
| 已推进 | 已跳过多少个章节 |
| 冷却 | 提交答案后的冷却倒计时 |
| 停滞 | 多久没有实质进展 |
| 自救 | 自救等级和最近几条自救日志 |

**面板底部两个按钮：**

- **🤖 AI 设置** —— 填 / 修改 / 清除 Key，填完自动测试连通性
- **🧹 清除所有痕迹** —— 清空密钥、全局标记、伪装 Hook、面板本身（清完建议刷新页面）

## 技术要点

几个踩过的坑，写下来供参考：

1. **`<video>` 元素是延迟创建的**
   学习通使用 video.js，进入新章节时只渲染海报和大播放按钮，`<video>` 要点了才创建。所以「找不到 video」是正常状态，需要去点 `.vjs-big-play-button`。

2. **「继续学习」按钮不会被移除**
   弹题答完后学习通不删这个按钮，导致「有继续学习按钮 = 弹题未完成」这个判断永远成立。正确做法是看视频是否真的在前进。

3. **「已完成」字样不止出现在测验上**
   目录侧边栏的视频任务点也有「已完成」标记，直接按文字判断会把整节课误判成测验已完成。

4. **`@match` 要覆盖多个学习通节点**
   `*://*.chaoxing.com/*` 一条通配符覆盖所有学校节点，不包含任何个人课程信息。

5. **反调试 hook 会反噬自己**
   脚本把 `document.hidden` 伪装成 `false`，于是自己的 `visibilitychange` 判断失效了。需要读真实的 `Object.getOwnPropertyDescriptor(Document.prototype, 'hidden').get.call(document)`。

6. **学习通不删「继续学习」按钮，也不删目录里的「章节测验」节点**
   按文字全局搜索「章节测验」会点中侧边栏的章节节点，导致跳过中间小节、鼠标光标乱跳。必须限定在顶部 tab 条 `.prev_list` 内。

7. **闯关模式下「跳过」会失效**
   新版学习通有章节锁定（提示「需完成之前闯关任务点，该章节才可解锁」），点目录树也跳不过去。只有真正完成任务点才能推进——这就是本脚本坚持「降速重播」而不是「跳过」的原因。

8. **调 AI 必须保持 `@grant none`**
   脚本要 hook `HTMLMediaElement.prototype.playbackRate` 来伪装倍速，这要求跑在页面上下文。所以不能改用 `GM_xmlhttpRequest`（那会进沙箱），只能用 `fetch` 直接调 DeepSeek（已验证它允许跨域）。
