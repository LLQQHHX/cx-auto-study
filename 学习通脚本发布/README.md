# 学习通自动化 油猴

一个跑在 Tampermonkey 里的学习通（超星）自动刷课脚本。

自动播放视频、自动答弹题、自动做章节测验、自动推进下一节——目标是把它丢在后台，让它自己把课程刷完。

> **定位说明：这是「自动刷完课程」的工具，不是「考满分」的工具。**
> 章节测验为随机作答，正确率不保证。如果测验分数影响你的成绩，请自己作答。

---

## 功能

| 功能 | 说明 |
|---|---|
| 自动播放 | 进入视频页自动开始播放，静音 + 2x 倍速 |
| 自适应降速 | 2x 播完任务点不通过时，自动降到 1.5x / 1.25x / 1x 从头重播 |
| 自动答弹题 | 视频中途弹出的对错题，答错自动换选项，穷举到答对为止 |
| 自动章节测验 | 切到测验 tab、逐题选择、提交、确认 |
| 自动下一节 | 本节完成后自动点「下一节」 |
| 空章节直通 | 没有视频没有题目的导学章节，8 秒后自动跳过 |
| 无测验直通 | 本节没有章节测验时，直接进入下一节 |
| 掉线自恢复 | 切到后台再回来，自动重置状态继续刷，不会误判卡死 |
| 面板可拖动 | 面板固定在右下角，可拖动到任意位置 |
| 环境自检 | 启动时在控制台打印浏览器/屏幕/iframe 可达性等信息 |

## 安装

### 1. 装 Tampermonkey（篡改猴）

- Chrome / Edge：[Chrome 应用商店](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- Firefox：[Firefox 附加组件](https://addons.mozilla.org/firefox/addon/tampermonkey/)

### 2. 装本脚本

**方式 A（推荐）**：点击仓库里的 [cx-auto-study.user.js](./cx-auto-study.user.js)，在打开的文件页面点右上角 **Raw**，Tampermonkey 会自动弹出安装页，点「安装」。

**方式 B（拖入）**：把 `.user.js` 文件下载到本地，直接拖进浏览器窗口，弹出安装页后点「安装」。

### 3. 开始使用

打开学习通课程页面（`mooc1.chaoxing.com/mycourse/...`），右上角出现 `📚 刷课` 面板即成功。

**不需要按 F12，不需要按 Ctrl+F8。**

## 常见问题

### 为什么不用按 Ctrl+F8？

学习通页面会注入 `(function anonymous(){ debugger; })()` 来阻止调试。
但 `debugger` 语句**只在 DevTools 打开时才真的暂停**。油猴脚本不需要开 DevTools，所以这段注入对脚本完全无影响。

### 2x 播完任务点没完成怎么办？

学习通要求「观看时长 ≥ 总时长的 90%」，2x 播完实际只花了 50% 的时间，所以有些课不通过。

脚本会自动处理：检测到点下一节后章节没变，就降到 1.5x 重播；还不行降到 1.25x、1x。面板上「试速」一行能看到当前降速状态。

### 章节测验的答案准吗？

**不准。** 脚本对章节测验是随机选选项。

原因：纯前端脚本没有知识库也没有推理能力，学习通的题库里还有大量图片题和公式题，脚本连题干都读不到。接入大模型 API 需要你自己配 Key、付费用，且跨域容易被拦，所以没做。

如果这门课的测验分数重要，请自己先做完测验，再让脚本跑后面的部分。

### 为什么状态偶尔变红？

一般是切到后台太久。浏览器会节流后台标签页的定时器，导致脚本以为卡住了。

切回前台后脚本会自动恢复（会打印「从后台恢复」日志），不需要手动干预。

### 卡住了怎么办？

1. 看面板「停滯」那一行，如果超时了，脚本会自动尝试三级自救
2. 自救无效会显示「自救无效，已停手」，这时刷新页面重新开始即可
3. 刷新后脚本会从当前章节继续

### 会不会重复执行？

不会。脚本内用 `window.__CX_AUTO_STUDY_V49__` 做了防重复注入标记。

但**不建议在油猴版运行时再去控制台粘贴一次代码**，那会导致两套循环叠加。

## 面板说明

| 字段 | 含义 |
|---|---|
| 状态 | 当前在做什么（绿=正常，橙=等待，红=异常） |
| 倍速 | 当前实际播放倍速（对外伪装为 1x） |
| 试速 | 降速次数和降速阶梯 |
| 进度 | 当前视频播放进度 |
| 最远 | 本次播放到达过的最远位置（用于防回退） |
| 修复 | 回退修复次数 |
| 已推进 | 已跳过多少个章节 |
| 冷却 | 提交答案后的冷却倒计时 |
| 停滞 | 多久没有实质进展 |
| 自救 | 自救等级和最近几条自救日志 |

标题栏可拖动，点 `−` 可收起面板（不影响运行）。

## 技术要点

几个踩过的坑，写下来供参考：

1. **`<video>` 元素是延迟创建的**
   学习通使用 video.js，进入新章节时只渲染海报和大播放按钮，`<video>` 要点了才创建。所以「找不到 video」是正常状态，需要去点 `.vjs-big-play-button`。

2. **「继续学习」按钮不会被移除**
   弹题答完后学习通不删这个按钮，导致「有继续学习按钮 = 弹题未完成」这个判断永远成立。正确做法是看视频是否真的在前进。

3. **「已完成」字样不止出现在测验上**
   目录侧边栏的视频任务点也有「已完成」标记，直接按文字判断会把整节课误判成测验已完成。

4. **`@match` 只写平台域名**
   `https://*.chaoxing.com/mycourse/*` 一条通配符覆盖所有学校节点，不包含任何个人课程信息。

5. **反调试 hook 会反噬自己**
   脚本把 `document.hidden` 伪装成 `false`，于是自己的 `visibilitychange` 判断失效了。需要读真实的 `Object.getOwnPropertyDescriptor(Document.prototype, 'hidden').get.call(document)`。
